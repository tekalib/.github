# Security Policy

## Supported versions

Only the latest release of each repository is supported. Earlier tags receive no fixes.

## Reporting a vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Email **hello@tekalib.com** with:

- The product / repository name
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will acknowledge your report within 48 hours and work to address it on a best-effort basis.
